How to install:

- Click <> Code (the green button)
- Click Download Zip
- You will receive a zip file
- Extract that zip file (the name of the zip is Custom-Elin-Mods-main)
- You will see a folder named Custom-Elin-Mods-main after extracting
- Go into that folder and drag and drop the mods into Elin/Package
- and you're good to go
